P| Standard O-Rings &rarr; Using the metric O-ring cross-reference chart to spec your partEngineers and buyers reach for a metric O-ring size cross-reference table when a drawing calls out one standard but their seal groove, mating hardware or supplier catalog speaks another. This chart lets you convert an O-ring size across AS568 dash numbers, ISO 3601, DIN 3771, JIS B 2401, BS 1806/4518, SMS 1586 and NF T 47-501 so you can confirm the true inside diameter and cross-section before you commit to a size. Use it to translate a legacy part number, match a metric o-ring size to an imported assembly, or verify that an equivalent listing actually shares the same ID and CS.
